# Manual

Abre la web y elige documentos recientes o archivo histórico. Consulta las tres categorías, busca por palabras o filtra por tema. Pulsa el título de una ficha para consultar sus fuentes y la página del PDF.

Pulsa PP o Vox en una ficha para seleccionarlo; vuelve a pulsar para quitarlo o elige el otro para cambiarlo. Ver recuento muestra una suma literal por partido. No calcula afinidad ni recomienda votos. El borrado afecta solo a la edición activa.

En Documentos puedes descargar los PDF del PP y abrir los de VOX desde el servidor oficial. Las selecciones se guardan en ese navegador; otro dispositivo tiene su propio recuento.
