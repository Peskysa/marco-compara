# Privacidad

No hay cuentas, analítica, cookies propias ni servidor que reciba selecciones. El navegador guarda las opciones en localStorage. Se borran desde el recuento o los datos del sitio. Los visitantes tienen selecciones independientes.

GitHub Pages puede registrar datos técnicos de acceso conforme a la política de GitHub. Los servidores de PP y VOX reciben las visitas cuando abres sus enlaces. No se envían selecciones a esos servidores.
