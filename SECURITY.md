# Seguridad

La aplicación es estática y no recibe las selecciones de visitantes. No hay cuentas, claves API ni base de datos. No introducir secretos en incidencias públicas. Para fallos sensibles, usar el aviso privado de seguridad del repositorio si está disponible.

La licencia no garantiza ausencia de errores. La revisión local cubre pruebas de datos e interfaz; no equivale a una auditoría completa.
